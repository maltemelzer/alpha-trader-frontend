# Charts

Plotly-Templates für Server-Rendering, Notebooks und Exporte (Python `plotly.io`, R, statische Bilder). Sie enthalten dieselben Werte wie das Web-Theme `bankiersgruenPlotly()`, nur als feste Hex-Werte.

- `plotly-template.json` – Standard (Darkmode).
- `plotly-template-farbenblind.json` – nur die Kerzenfarben für den Farbenblind-Modus, wird über das Standard-Template gelegt. Kurslinien setzt der Code selbst auf `gain`/`loss`.

Schriften: Libre Franklin, Source Serif 4 und IBM Plex Mono müssen auf dem Render-System installiert sein, sonst greifen die Fallbacks.
